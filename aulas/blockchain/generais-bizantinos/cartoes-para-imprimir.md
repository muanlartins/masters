# Cartões para imprimir — Guerreiros Bizantinos

Imprima, recorte e entregue um por voluntário. Cada cartão diz **exatamente**
o que a pessoa fala — o resultado é determinístico.

> Dica: cole cada cartão num papel dobrado tipo "tenda" pra ficar de pé no
> canto do voluntário, com o nome do papel (COMANDANTE / TENENTE 1 / TENENTE 2)
> visível para a turma e o roteiro virado para o voluntário.

---

## JOGO PRINCIPAL — o comandante é o traidor

```
┌─────────────────────────────────────────────────┐
│  COMANDANTE                                       │
│  (segredo: você é TRAIDOR — não conte a ninguém)  │
│                                                   │
│  CENA 1 — passe a ordem, em voz alta:             │
│    • para o TENENTE 1, diga:  "ATACAR"            │
│    • para o TENENTE 2, diga:  "RECUAR"            │
│                                                   │
│  CENA 2 — fique quieto e observe a confusão.      │
└─────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────┐
│  TENENTE 1   (LEAL)                               │
│                                                   │
│  CENA 1 — anuncie em voz alta a ordem que o       │
│  comandante te deu.                               │
│                                                   │
│  CENA 2 — diga, virado para o TENENTE 2:          │
│    "O comandante me disse ATACAR."                │
│                                                   │
│  Você é leal: obedeceria a ordem que recebeu.     │
└─────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────┐
│  TENENTE 2   (LEAL)                               │
│                                                   │
│  CENA 1 — anuncie em voz alta a ordem que o       │
│  comandante te deu.                               │
│                                                   │
│  CENA 2 — diga, virado para o TENENTE 1:          │
│    "O comandante me disse RECUAR."                │
│                                                   │
│  Você é leal: obedeceria a ordem que recebeu.     │
└─────────────────────────────────────────────────┘
```

## JOGO OPCIONAL — o traidor é o Tenente 2

Use para provar a *indistinguibilidade*: o Tenente 1 (leal) recebe as mesmas
mensagens do jogo principal, mas agora o culpado é outro.

```
┌─────────────────────────────────────────────────┐
│  COMANDANTE   (LEAL)                              │
│                                                   │
│  CENA 1 — passe a MESMA ordem para os dois:       │
│    • para o TENENTE 1, diga:  "ATACAR"            │
│    • para o TENENTE 2, diga:  "ATACAR"            │
│                                                   │
│  CENA 2 — fique quieto e observe.                 │
└─────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────┐
│  TENENTE 1   (LEAL)                               │
│                                                   │
│  CENA 1 — anuncie a ordem que recebeu ("ATACAR"). │
│                                                   │
│  CENA 2 — diga ao TENENTE 2:                      │
│    "O comandante me disse ATACAR."                │
└─────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────┐
│  TENENTE 2   (segredo: TRAIDOR — não conte)       │
│                                                   │
│  CENA 1 — anuncie em voz alta: "ATACAR"           │
│  (a ordem verdadeira que recebeu).                │
│                                                   │
│  CENA 2 — MINTA para o TENENTE 1:                 │
│    "O comandante me disse RECUAR."                │
└─────────────────────────────────────────────────┘
```

> **A revelação:** na Cena 2, o Tenente 1 (leal) ouve nos dois jogos a mesma
> coisa — "comandante: ATACAR" + "outro tenente: o comandante disse RECUAR".
> Ele não consegue distinguir um comandante traidor de um colega traidor.
> Por isso, com 3 generais, 1 traidor é insolúvel.
