\section{Related Work}
\label{sec:related}

This section surveys three bodies of work the paper draws on and one it must build past: weightless neural networks, the machine-unlearning literature, the membership-inference tools used to verify forgetting, and the Where's-Waldo task as a benchmark.

Weightless neural networks recognize patterns with random-access memory rather than tunable weights: the n-tuple method of Bledsoe and Browning samples bit-tuples from the input and looks them up in tables~\cite{bledsoe1959ntuple}, and the WiSARD architecture organizes those tables into one discriminator per class~\cite{aleksander1984wisard}. The wisardpkg library provides a maintained implementation~\cite{carvalho2020wisardpkg}, and the regression WiSARD extends the model from classification to real-valued outputs~\cite{lusquino2020rew}, which we use for localization. This literature consistently presents weightless models as fast, single-pass, online-trainable classifiers, and studies their accuracy and memory footprint. It does not study the consequence we exploit: because each table cell is an independent additive counter, the trained model is a sum of per-example contributions, and deletion is exact by construction rather than approximate.

Machine unlearning seeks the model that retraining on the surviving data would have produced, without paying the full retraining cost~\cite{caoyang2015,nguyen2022survey,xu2023survey}. Exact methods bound that cost structurally: SISA shards the data and retrains only the affected shard~\cite{bourtoule2021sisa}, while data-removal-enabled (DaRE) forests cache split statistics so most deletions touch few subtrees~\cite{brophy2021dare}; approximate methods instead perturb a trained model toward the unlearned state, for example by gradient ascent on the deleted example, trading exactness for speed. Each technique is engineered around a model class---shards for deep networks, cached statistics for forests, gradient steps for differentiable models---and the exact variants still reconstruct substructure or spend large memory to do so. A newer direction instead makes forgetting native to the architecture: MUNKEY deletes by removing instance keys from a memory-augmented transformer rather than by updating weights~\cite{laguna2026munkey}. Weightless networks share that goal of architecture-native deletion but reach it by construction, with a deletion that is an exact counter subtraction, bit-identical to never-training; we benchmark it against SISA, DaRE, gradient ascent, and gold-standard retraining on shared data and metrics.

Whether a deletion truly removed a record is itself measurable: membership-inference attacks ask whether a given example was in the training set, and a clean deletion should drive their advantage to chance~\cite{shokri2017mia}. The strongest form calibrates each example against shadow models~\cite{carlini2022lira}, and for unlearning in particular per-example audits are needed to avoid a false sense of privacy~\cite{hayes2024ulira}, since unlearning can paradoxically \emph{increase} leakage when the before- and after-deletion models are both exposed~\cite{chen2021mia}. These attacks are usually mounted against deep networks and approximate unlearning, where residual traces are expected; we adopt the membership-inference AUC as the forgetting check for weightless deletion, where the additive structure predicts AUC at chance and the experiment confirms it.

Visual search in the style of \emph{Where's Waldo?} has been approached as a single-image detection problem, with machine-learning treatments that locate the character on a scanned page~\cite{barthelmes2021wally}. These treatments optimize detection on the handful of published illustrations, where one labeled instance per page suffices. Our use of the task is different: we need many balanced instances of each character and a known target location in every scene, so that identities can be deleted in volume and audited and a weightless localizer can be scored on a level field, which the few annotated real pages cannot provide. In contrast to all of the above, this paper builds a synthetic, calibrated Where's-Waldo benchmark and treats weightless networks as an exact, residual-free unlearning substrate, positioning them as a latency-first peer to accuracy-first exact methods such as DaRE rather than as a replacement for them.
